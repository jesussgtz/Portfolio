#  ConnectaTel Customer Analysis

##  Objective
Analyze customer behavior for ConnectaTel to identify usage patterns, segment users, and provide business recommendations to improve telecom plans.

---

## Datasets Used
- plans.csv → plan details (price, minutes, GB, extra costs)
- users_latam.csv → customer information (age, city, plan)
- usage.csv → customer usage (calls and messages)

---

## Analysis Process
1. Data exploration (structure, types, missing values)
2. Data cleaning (handling nulls and invalid values)
3. Feature engineering (aggregated metrics per user)
4. Data analysis and visualization
5. Customer segmentation (usage level and age groups)

---

##  How to Run
1. Open the notebook in Google Colab or Jupyter Notebook  
2. Run all cells sequentially  

---

##  Reproducibility
To reproduce the analysis:
- Use the same datasets (`plans.csv`, `users_latam.csv`, `usage.csv`)
- Ensure Python environment with:
  - pandas
  - numpy
  - matplotlib
  - seaborn

---

##  Key Insights
- Most users fall into the medium usage segment  
- High-usage users represent high-value customers  
- Opportunities exist to optimize telecom plans
